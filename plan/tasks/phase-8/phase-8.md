# Phase 8: 질의 응답 시스템

## 📋 개요

Phase 8는 자연어 질의를 처리하여 그래프 기반 답변을 생성하는 시스템을 구현하는 단계입니다.

## 🎯 목표

- Intent 추출 (Gemini Structured Output)
- Cypher 쿼리 빌더
- Vector 검색 (하이브리드)
- 답변 생성 (스트리밍)
- REST API 구현

## 📥 입력

- 사용자 자연어 질의
- FalkorDB 그래프 데이터

## 📤 출력

- 구조화된 답변
- 출처 정보 (Document, Section)
