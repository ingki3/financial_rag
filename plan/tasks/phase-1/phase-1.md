# Phase 1: 환경 설정

## 📋 개요

Phase 1은 프로젝트 개발 및 실행을 위한 기본 환경을 설정하는 단계입니다. Docker를 통한 FalkorDB 설치, Python 가상환경 구축, 의존성 관리, 환경 변수 설정을 포함합니다.

## 🎯 목표

- FalkorDB Docker 컨테이너 실행
- Python 가상환경 생성 및 의존성 설치
- 프로젝트 설정 파일 생성

## 📥 입력

- 없음 (초기 설정)

## 📤 출력

- 실행 중인 FalkorDB Docker 컨테이너
- Python 가상환경 (`venv/`)
- `requirements.txt` 파일
- `.env.example` 파일
